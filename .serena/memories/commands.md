# Suggested Commands

## Development
```bash
npm run dev      # 開発サーバー起動（Next.js）
npm run build    # プロダクションビルド
npm run start    # プロダクションサーバー起動
npm run lint     # ESLint 実行
```

## No Test Framework
テストフレームワークは設定されていない。

## After Task Completion
1. `npm run lint` でESLintエラーがないか確認する
2. `docs/00X_*.md` の対応する Todo チェックボックスを `[ ]` → `[x]` に更新する
